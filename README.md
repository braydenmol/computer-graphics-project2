# Cube World: Mountain Landscape

Student project based on the instructor-provided `webgl-cubes-v2/index.js` example. Uses plain WebGL 1 and the same reusable cube buffer, individual `uModel` transforms, and instructor-style matrix helpers.

## Run
Open a terminal in this folder and run `py -m http.server 8000`, then visit http://localhost:8000. Opening index.html directly may block PNG loading.
